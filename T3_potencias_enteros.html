Potencias de números enteros

Recuerda: la regla de los signos

Lo usaste al multiplicar enteros (fichas 3 y 4):

(+)·(+) = +  (−)·(−) = +  (+)·(−) = −  (−)·(+) = −

Cuando hay muchos factores, cuenta cuántos son negativos:

• número par de negativos → resultado positivo
• número impar de negativos → resultado negativo

Ejemplo: (−2) · (−3) · (−1): hay 3 negativos (impar) → signo −.  Y 2 · 3 · 1 = 6.  Resultado: −6.

¿Qué es una potencia?

Una potencia es una forma abreviada de escribir una multiplicación de factores iguales.

an = a · a · a · … · a  (n veces)

a es la base: el número que se repite.
n es el exponente: cuántas veces se repite.

Ejemplo: 5 · 5 · 5 = 53. La base es 5 y el exponente es 3.
Si la base es negativa, va entre paréntesis: (−4) · (−4) = (−4)2.

Así, 75 se lee «7 a la quinta» y (−8)3 se lee «menos 8 al cubo».

El signo de una potencia

Como una potencia es una multiplicación, su signo sale de la regla de los signos:

(−3)4 = +81
Base negativa y exponente impar

(−3)3 = −27

¡Ojo al paréntesis! En (−3)4 la base es −3. En −34 la base es 3 y el signo − está fuera: no se eleva.

(−3)4 = (−3)·(−3)·(−3)·(−3) = +81    −34 = −(3·3·3·3) = −81

Ejemplos resueltos paso a paso

Pulsa «Siguiente paso» y piensa tú el paso antes de verlo.

Ejemplo 1. Calcula 23.
1. Escribo la multiplicación: 23 = 2 · 2 · 2.
2. Multiplico: 2 · 2 = 4, y 4 · 2 = 8.
3. Resultado: 23 = 8. (No es 2 · 3 = 6).
Ejemplo 2. Calcula (−2)3.
1. Miro la base: −2, negativa. Miro el exponente: 3, impar.
2. Base negativa y exponente impar → signo −.
3. Calculo sin signo: 23 = 2 · 2 · 2 = 8.
4. Junto signo y número: (−2)3 = −8.
Ejemplo 3. Calcula (−2)4.
1. Base −2 negativa; exponente 4 par.
2. Base negativa y exponente par → signo +.
3. Sin signo: 24 = 2 · 2 · 2 · 2 = 16.
4. Resultado: (−2)4 = +16.
Ejemplo 4. Calcula −24 (¡sin paréntesis!).
1. No hay paréntesis: la base es 2 (positiva). El signo − está delante y no se eleva.
2. Calculo la potencia: 24 = 16.
3. Pongo el − de delante: −24 = −16. Compara con el ejemplo 3: ¡cambia el signo!
Ejemplo 5. Calcula (−1)7 y (−1)10.
1. 1 multiplicado por sí mismo siempre da 1. Solo hay que decidir el signo.
2. Exponente 7, impar → (−1)7 = −1.
3. Exponente 10, par → (−1)10 = +1.
